### About the Experiment 

This experiment focuses on simulating the transmission of live sensor data to an IoT cloud platform using HTTP protocols.  
It demonstrates how ESP8266/ESP32 modules establish Wi-Fi connectivity and communicate with web servers.  
Students learn the structure of HTTP requests such as GET and POST methods for data transfer.  
The experiment introduces client–server architecture and REST-based communication in IoT systems.  
The simulation provides practical understanding of real-time cloud data publishing and remote monitoring.
